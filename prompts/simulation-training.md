# CT-OS V4.0 — 推演沙盘 / 模拟训练 需求提示词

## 背景

CT-OS V4.0 定位为「交易教练」，不是交易机器人。核心理念：**记录 → 纠正 → 提醒**。

「推演沙盘」是六把武器中最核心的差异化功能 —— 让用户在历史行情中"重活一遍"，用缠论视角做模拟交易决策，训练盘感和纪律。

## 功能需求

### 核心：历史回放 + 模拟交易

用户选择一只股票、一个起始日期，系统从该日期开始"逐K线播放"，就像在"那一天"看盘一样。用户看图做判断：买入、卖出、持有。播完一段后，系统给出评分。

### 1. 训练模式入口
- 在导航栏新增「🎮 模拟训练」页面
- 训练前选择：股票代码 + 起始日期 + 周期（日线/30分）
- 可选：难度模式（新手=显示缠论标注 / 进阶=裸K）

### 2. K线回放引擎
- 从起始日期开始，每次加载 N 根K线（初始可见80根）
- 用户点「下一根」或按空格键 → 追加1根K线
- 支持自动播放（可调速：0.5s/1s/2s 每根）
- 每追加一根K线，缠论结构实时重新计算并渲染
- 右侧遮罩：未来K线不可见

### 3. 模拟交易面板
- 底部悬浮面板：
  - 💰 当前资金（初始100万）
  - 📊 当前持仓（股数 + 成本 + 浮盈）
  - 🔴 买入按钮（输入股数或金额比例）
  - 🟢 卖出按钮（全仓/半仓/自定义）
- 交易记录实时列表
- 当前价格 + 涨跌幅显示

### 4. 训练结果评估
- 回放结束（到当前日期或用户停止）后，显示成绩单：
  - 总收益率 vs 基准（买入持有）
  - 最大回撤
  - 交易次数 + 胜率
  - 关键决策点回顾（买卖时的K线截图 + 当时的缠论结构）
  - 行为评分：追高次数、止损执行率、趋势持仓天数

### 5. 缠论辅助（可选显示）
- 训练中可以打开/关闭缠论图层（笔/段/中枢）
- 推演雷达同步显示当时的多周期状态
- 提供"缠论教练提示"：当前处于中枢震荡/趋势中？

## 技术约束

- 前端：React + KLineCharts，复用现有 chanOverlay.js
- 后端：FastAPI，复用现有 chan_detail_service.py
- 关键 API：`GET /api/chan/detail/{symbol}?freq=day&count=N&end_date=YYYY-MM-DD`
  - 需要新增 `end_date` 参数支持截断历史数据
- 模拟交易数据不需要持久化到数据库（纯前端 state）
- 训练结果可选保存到 localStorage

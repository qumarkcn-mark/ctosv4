# CT-OS V4.0 — 缠论智能选股 需求提示词

## 背景

CT-OS V4.0 定位为「交易教练」。选股是交易的第一步——从 5000+ 只 A 股中找到处于"缠论买点"附近的标的，再用 AI 做二次筛选，帮用户缩小注意力范围。

## 已有基础

### 1. 缠论引擎 (chan_engine)
- 笔/线段/中枢/买卖点 已实现
- 同级别分解 已实现
- `chan_detail_service.py` 可解析单只股票的缠论结构

### 2. 前代实现参考 (chan.py/App/ashare_bsp_scanner_gui.py)
- PyQt6 桌面端扫描器（已验证可行）
- 核心逻辑：遍历 A 股 → 缠论分析 → 检测最近 3 天内的买卖点
- 过滤：剔除 ST、科创板、北交所、B股、停牌
- 数据源：akshare (A 股实时行情)

### 3. K线数据
- BaoStock: 日线/分钟级历史数据
- 腾讯行情 API: 实时价格
- SQLite 本地缓存

### 4. CT-OS V4 前端
- KLineCharts 图表 + 缠论 overlay
- 搜索选股 + 自选股面板
- 图层控制系统

## 功能需求

### Phase 1: 缠论选股扫描器

#### 1.1 盘后扫描（定时任务）
- 每天收盘后（15:30）自动运行，或手动触发
- **扫描范围**：A 股主板+中小板（约3000只，排除ST/北交所/科创板）
- **扫描逻辑**（复用 chan_engine）：
  1. 拉取每只股票最近 250 根日线
  2. 运行缠论分解：笔 → 线段 → 中枢 → 买卖点
  3. 检测最近 N 天内是否出现以下信号：
     - 🟢 一类买点（趋势背驰）
     - 🟡 二类买点（中枢回拉确认）  
     - 🔵 三类买点（离开中枢不回来）
     - 🔴 一类卖点 / 二类卖点 / 三类卖点
- **结果存储**：写入 SQLite `scan_results` 表

#### 1.2 选股结果页面
- 在导航栏新增「📡 选股雷达」页面
- 展示最近一次扫描的结果列表：
  - 股票代码 + 名称
  - 买点类型 + 出现日期
  - 当前价格 + 涨跌幅
  - 缠论状态标签（趋势/中枢震荡/背驰预警）
- 点击股票 → 跳转到「缠论看盘」页直接看图
- 筛选器：按买点类型、市场（沪/深）、行业过滤

### Phase 2: AI 二次筛选

#### 2.1 设计思路
缠论扫描可能产出 50-200 只股票，用户没有精力逐个看图。
AI 负责做"精选"——从缠论候选池中挑出最优的 5-10 只。

#### 2.2 AI 筛选维度
调用 DeepSeek V3 API，对每只候选股做综合评估：

```
Prompt 模板：
你是一位专业的缠论分析师。请对以下股票进行评分（0-100分）：

股票：{name} ({symbol})
缠论结构：
- 当前笔方向：{bi_direction}
- 线段方向：{seg_direction} 
- 最近中枢：[{zd}, {zg}]，当前价格相对中枢位置：{position}
- 买卖点类型：{bsp_type}
- MACD 背驰情况：{macd_divergence}

基本面（可选）：
- 市值：{market_cap}
- PE/PB：{pe}/{pb}
- 近3月涨跌幅：{change_3m}

请从以下维度评分：
1. 缠论结构质量（30分）：买点是否标准、中枢是否清晰
2. 多级别共振（25分）：日线/30分/5分是否方向一致
3. 量价配合（20分）：量能是否配合缠论结构
4. 安全边际（25分）：距离中枢/止损位的空间
```

#### 2.3 AI 评分展示
- 在选股结果页增加「AI 评分」列
- 支持按 AI 评分排序
- 点击评分 → 展开 AI 分析详情（文字说明）
- 顶部显示「AI 精选 TOP 10」卡片组

### Phase 3: 实时监控（增强）
- 自选股 + AI 精选股自动加入监控池
- 当价格触及买点附近时推送提醒
- 结合止损看门狗，买入后自动设置 ATR 止损

## 技术方案

### 后端新增

```
server/
├── api/
│   └── scanner.py           # 扫描 API 路由
├── services/
│   ├── stock_scanner.py     # 扫描引擎（批量缠论分析）
```

### API 设计

```
POST /api/scanner/run              # 手动触发扫描
GET  /api/scanner/results          # 获取最新扫描结果  
GET  /api/scanner/results/{id}     # 获取单只股票的缠论详情
POST /api/scanner/ai-filter        # 触发 AI 筛选
GET  /api/scanner/ai-top           # 获取 AI 精选 TOP N
```

### 前端新增

```
web/src/
├── pages/
│   └── ScannerView.jsx      # 选股雷达页面
└── components/
    ├── ScanResultList.jsx    # 扫描结果列表
    ├── AiScoreCard.jsx       # AI 评分卡片
    └── ScanFilter.jsx        # 筛选器
```

## 性能考虑

- 3000 只股票 × 250 根 K 线 ≈ 单线程扫描需要 30-60 分钟
- 方案：4-8 线程并发 + 增量扫描（只扫描今天有交易的股票）
- AI 筛选：批量调用，每批 10 只，控制 API 成本

## 不做的事情

- 不做自动交易、不发委托单
- 不做基本面深度分析（仅作辅助维度）
- 不做行业/板块轮动分析（第一版）
- AI 给出的是"参考评分"，不是"买入建议"

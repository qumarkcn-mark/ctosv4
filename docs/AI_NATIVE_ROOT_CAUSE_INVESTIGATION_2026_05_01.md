# AI Native Radar 根因排查记录（2026-05-01）

## 结论

这轮“不像黄金案例”的主因不是前端展示，也不是单纯 Prompt，也不是 DeepSeek 与 Gemini 的文风差异。

真正的分叉发生在结构事实层：黄金案例使用的是 `get_chan_multi_level(symbol, ["day", "30", "5"])` 得到的近端战术中枢；当前 Radar API 使用的是 `chan_adapter.analyze_structure(symbol, ["week", "day", "60", "30", "15", "5"])` 得到的全级别结构。两种调用会让 chan.py 在 5m/30m 上生成不同的最新中枢，导致 Evidence Pack 的主战场完全不同。

AI 后面只是忠实跟着输入事实走，所以会偏航。

## 关键证据

### 汇川技术（sz.300124）

黄金脚本/`day,30,5` 专用结构：

- 30m 最新中枢：`66.98 - 68.63`，`dd=64.55`
- 5m 最新中枢：`65.53 - 66.38`，`dd=65.30`
- 当前价 `68.60` 接近 30m ZG，因此黄金叙事是“深 V 重返 30m 中枢，等待回踩确认 5m 三买”。

当前 Radar 全级别结构：

- 30m 最新中枢：`69.96 - 71.40`
- 5m 最新中枢：`66.01 - 66.88`
- 当前价 `68.60` 低于 30m ZD，因此系统只能判成 `BREAKDOWN_BELOW_30M`。

这不是模型没写好，而是输入事实已经把“重返中枢”变成了“跌破 30m”。

### 澜起科技（sh.688008）

黄金脚本/`day,30,5` 专用结构：

- 5m 上方旧中枢：`175.51 - 180.00`
- 5m 当前中枢：`168.50 - 170.35`
- 当前价 `173.30` 位于两个 5m 中枢之间，因此黄金叙事是“颈线反抽，测试三卖”。

当前 Radar 全级别结构：

- 5m 最新中枢：`157.68 - 159.00`
- 30m 最新中枢：`144.46 - 145.50`
- 当前价远高于这些中枢，所以系统更容易写成“结构真空期/强势延伸”，而不是“两 5m 中枢之间的颈线战”。

### 天孚通信（sz.300394）

黄金脚本/`day,30,5` 专用结构：

- 5m 最新中枢：`310.01 - 313.99`，`dd=307.83`
- 当前价 `307.50` 贴着 5m 中枢下沿下方，因此黄金叙事是“高位雪崩后的下跌中继，310.01 是极短线强压”。

当前 Radar 全级别结构：

- quote 里有 `15.85 / 16.97`，所以动态防线可以补回来，但 `14.68` 这个关键底线在全级别结构里消失。

## 根因链路

1. 黄金案例的数据来自 scratch 脚本：
   - `scratch_chan_300124.py`
   - `scratch_chan_688008_new.py`
   - `scratch_chan_300394.py`
   - `scratch_chan_002176_jiangte.py`
   - 它们调用 `get_chan_multi_level(symbol, ["day", "30", "5"])`。

2. 当前 `/api/radar` 固定调用：
   - `analyze_structure(symbol, levels=["week", "day", "60", "30", "15", "5"], count=800)`

3. chan.py 多级别联动时，低级别结构会受到更高级别组合影响。同一个 symbol，在 `["day","30","5"]` 与 `["week","day","60","30","15","5"]` 下，5m/30m 中枢并不一致。

4. Evidence Pack 当前只拿 Radar API 的全级别结果，所以 AI 收到的是另一张战场地图。

## 判断

现在最优先要修的不是 Prompt。

Prompt 再霸道，也不能让模型在输入为“跌破 30m”的情况下稳定写出“重返 30m 中枢”；这会变成鼓励幻觉。Gemini 黄金案例之所以好，是因为它拿到的结构事实本身就是战术级近端结构。

也不是前端展示问题。前端只是把后端返回 Markdown 渲染出来，方向不对发生在 LLM 调用前。

DeepSeek/Gemini 可能影响表达锐度，但不是这轮偏航的第一原因。

## 建议下一步

先把 AI Native Radar 的结构输入从“全级别一锅炖”改成“双结构包”：

- `macro_structure`: 保留当前 `week/day/60/30/15/5`，只做大级别风险背景。
- `tactical_structure`: 单独调用 `day/30/5`，用于 AI 推演主战场。

Evidence Pack 的 `primary_context`、`must_use_levels`、`semantic_assertions` 应优先来自 `tactical_structure`。宏观结构只能作为风险注脚，不能覆盖近端战术结构。

这样可以让 6 个黄金案例重新拿到正确事实：

- 汇川：`66.98-68.63` 与 `65.53-66.38`
- 澜起：`175.51-180.00` 与 `168.50-170.35`
- 瑞芯微：`180.37 / 187.58`
- 兆易：`309.75 / 304.05`
- 江特：`15.85` 动态防线 + `14.68` 近端底线
- 天孚：`310.01-313.99`
